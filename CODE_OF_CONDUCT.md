# Code of Conduct

## Our Pledge

We are committed to providing a friendly, respectful, inclusive, and harassment-free environment for everyone participating in this project.

## Our Standards

Examples of positive behavior include:

- Using welcoming and inclusive language.
- Respecting different opinions and experiences.
- Accepting constructive criticism.
- Supporting other contributors.
- Focusing on what is best for the project and community.

Unacceptable behavior includes:

- Harassment or discrimination.
- Offensive comments or personal attacks.
- Publishing private information without permission.
- Trolling or other disruptive behavior.

## Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing the standards of this Code of Conduct.

## Scope

This Code of Conduct applies to all project spaces, including GitHub repositories, issues, pull requests, discussions, and other community interactions.

## Enforcement Guidelines

Project maintainers may take appropriate action depending on the severity of the violation:

1. Warning the contributor.
2. Temporarily restricting participation.
3. Removing inappropriate contributions.
4. Permanently excluding individuals for serious or repeated violations.
